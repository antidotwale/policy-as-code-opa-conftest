# policy-as-code-opa-conftest

Policy as code with OPA and Conftest checking Terraform plans and Kubernetes manifests.

> Personal lab project. Built in my own AWS, Azure and GitHub accounts for learning and practice. It is not work I did for any employer or client. Any secrets, keys or tokens shown in test data are fake.

## What this builds

A small set of Rego policies, such as no public buckets and no privileged containers, tests for each policy, and a CI job that blocks a plan that breaks them.
